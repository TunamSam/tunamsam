# Installation

Clone repository:

```bash
git clone https://github.com/USERNAME/tunamsam.git
```

Move into project folder:

```bash
cd tunamsam
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

# Build Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
